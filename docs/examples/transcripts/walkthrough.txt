Every endpoint once with curl (docs/examples/walkthrough.sh). Floats rounded to 3 decimals and base64 cut by pretty.py.
Recorded 2026-10-05 on Linux x86-64 (AMD Ryzen 7 7435HS, 16 threads), Python 3.12.3, fastapi 0.121.2, onnxruntime 1.23.2,
opencv-python-headless 4.12.0.88, pillow 12.0.0, numpy 2.2.6, uvicorn 0.38.0, one uvicorn process, client on the same machine.
Detector and classifier: the REAL files (models/best.onnx and models/disease_classifier/*), kept outside the repository.
Code state: Pillow bicubic crop resize, one embedder call per crop (the changes of 2026-10-05).
Service started with RATE_LIMIT_REQUESTS=1000. The classes are real model output; the true condition of the fish in the photo is not known.
