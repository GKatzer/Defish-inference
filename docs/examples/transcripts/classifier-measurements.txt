Classifier measurements (docs/examples/measure_classifier.py), real models, crops found by the real detector and cut from the original photos as /analyze does.
Recorded 2026-10-05 on an AMD Ryzen 7 7435HS (16 threads), onnxruntime 1.23.2, Python 3.12.3. Timings vary by up to about 30 % between runs on this machine.
Code state: Pillow bicubic crop resize, one embedder call per crop (the changes of 2026-10-05). The script keeps the PREVIOUS ways as options, so the
before/after comparison is reproducible without the old code: 'one call' = one embedder call for all crops (the previous implementation),
--opencv-resize = the previous crop resize.
